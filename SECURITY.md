# Security Notes

This is a public repository for Meta ad image assets only.

Do not commit:

- API keys, access tokens, passwords, cookies, or session files
- `.env` files or production configuration
- private customer data, order exports, lead lists, or personal information
- service account JSON files, certificates, SSH keys, or payment data
- private working files that are not intended to be public

Allowed content:

- Public ad images in `assets/`
- Public README or usage notes

Before adding a file, verify that it is intended to be publicly accessible on the open internet. Meta Ads can only fetch public direct URLs, so anything uploaded here should be safe to publish.
